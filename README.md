# spendwise-expense-tracker
A simple expense tracking application built with Python to record expenses and calculate total spending.

# version 1.0
This is the initial version of the project, focused on basic expense management and helping users keep track of their daily spending.

# features
- Add and record expenses
- Store expense details
- Organize expenses into categories
- View spending records
- Calculate total expenses
- Simple and user-friendly interface
- Built using Python

# technologies used
Python, Python Standard Libraries, Terminal/Command Line.
